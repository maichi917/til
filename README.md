# TIL (Today I Learned)

日々学んだことを短くメモしていくリポジトリ。長く書こうとすると続かないので、短く・素早く残すことを優先する。

## 書くタイミング

- Qiitaのコメントなどで新しいメソッド・テクニックを教わった時
- コードレビュー中に気になる実装（粗）を見つけた時
- 過去に書いたコードを読み返して理解し直した時
- AtCoderで新しい解法・テクニックを使った時

## エントリの書き方

1本あたり3〜10行程度。

- 学んだこと（1行）
- 最小限のコード例
- （あれば）出典リンク

新しいエントリを書いたら、下の一覧にも追記する。
